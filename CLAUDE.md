# Why_Ai — контракт проекта

## Язык

**Отвечай всегда на русском языке.** Это относится к объяснениям, выводам,
резюме, сообщениям коммитов, описаниям PR и тексту в планах.

Исключения — оставляй как есть, не переводя:
- код, имена файлов, путей, функций, переменных, флагов CLI;
- вывод команд, трейсбеки, логи, сообщения об ошибках;
- термины, у которых нет устоявшегося русского эквивалента
  (zone P/R, kill-switch, fallback, worktree, diff, commit gate).

Если пользователь пишет по-английски — всё равно отвечай по-русски,
пока он явно не попросит обратное.

## Что это за проект

Саморазвивающаяся мультиагентная система (Self-Evo Framework).
Топология и зоны — по `.ai-loop/policy/protected_paths.yaml`, он же
источник истины о том, что агенту можно менять:

- `Supervisor/` — неизменяемый пол безопасности (зона R). Не править.
- `Core/` — рантайм, ядро задач и `Core/dvpn/` (зона R).
- `Tool/connectors/` — коннекторы с внешними эффектами (зона R).
- `.ai-loop/policy/`, `.ai-loop/bin/`, `CODEOWNERS`, `.github/` — policy-плоскость
  (зона P). Агент не правит их никогда: это правила, по которым его судят.
- `Eye/`, `docs/`, `Tool/skills/` — свободная зона E.
- `tests/` — зона T.

## Правила работы

1. **Проверяй, а не пересказывай.** Прежде чем утверждать, что что-то
   реализовано, запусти это. В репозитории уже были случаи, когда документ
   описывал функциональность, которой нет.
2. **Не выдавай симуляцию за факт.** `Core/dvpn/` не выполняет сетевых
   операций: узлы захардкожены, ключи демонстрационные. Описывай это честно.
3. **Тест обязан уметь падать.** Прежде чем засчитать критерий выполненным,
   убедись, что тест краснеет на неверной реализации.
4. **Стартовый гейт:** `python run_mvp.py --self-test` должен возвращать 0.
   Код 10 означает, что система не проходит собственную проверку.
5. Перед коммитом: `python .ai-loop/bin/classify_diff.py --repo . --self-check`
   должен давать `ok: true`.

## Команды

```bash
python run_mvp.py --self-test                    # тесты + проверка целостности
python -m unittest discover -s tests -p "test_*.py"
python .ai-loop/bin/classify_diff.py --repo . --self-check

```
