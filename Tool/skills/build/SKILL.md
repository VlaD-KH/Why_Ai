# /build — Incremental Implementation Phase

## Purpose
Реализовать запланированный функционал инкрементально, по одному шагу за раз, строго в соответствии с утвержденной архитектурой.

## Operating Principles
1. **One Slice at a Time:** Не пытаться реализовать весь проект в одном шаге.
2. **Production-Ready Code:** Никаких заглушек (`TODO`, `implement logic here`). Полный, типизированный код.
3. **Language Rules:** Внутренняя логика и API на английском языке; все комментарии, докстринги и пользовательские тексты на русском.

## Steps
1. **Изоляция:** Запустить рабочий процесс в песочнице или отдельной ветке.
2. **Имплементация:** Написать чистый модульный код запланированного шага.
3. **Классификация диффа:** Запустить `classify_diff.py` поверх фактического диффа. При `require_human` немедленно остановиться и запросить подтверждение.
