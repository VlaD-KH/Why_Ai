# /code-simplify — Refactoring & Code Compression Phase

## Purpose
Устранить избыточную сложность, оптимизировать структуры данных и применить храповики размера (`Size Ratchets`).

## Operating Principles
1. **Clarity Over Cleverness:** Читаемый и прозрачный код всегда предпочтительнее «умных» запутанных трюков.
2. **Shrink-Only Mandate:** Успешная оптимизация модуля фиксирует новую нижнюю границу размера файла.
3. **Dead Code Elimination:** Удаление неиспользуемых импортов, функций и промежуточных временных структур.

## Steps
1. **Анализ кодовой базы:** Поиск дублирования логики и неиспользуемых компонентов.
2. **Рефакторинг:** Упрощение управляющих конструкций и типизации.
3. **Фиксация храповика:** Запись обновленных лимитов размера в реестр.
