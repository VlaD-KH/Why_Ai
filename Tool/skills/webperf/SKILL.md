# /webperf — Performance & Resource Audit Phase

## Purpose
Замерить реальную производительность, задержки телеметрии, потребление памяти и пропускную способность каналов до проведения оптимизаций.

## Operating Principles
1. **Measure Before Optimize:** Никаких преждевременных оптимизаций без численных замеров.
2. **Sub-100ms Target:** Время отклика компонентов телеметрии и проверки политик должно быть $< 100\text{ ms}$.
3. **No Memory Leaks:** Проверка утечек памяти при парсинге логов и потоков событий.

## Steps
1. **Бенчмаркинг:** Провести замеры времени выполнения ключевых операций (классификация диффа, расчет центральности графа ContextFit).
2. **Анализ узких мест:** Выявить неэффективные алгоритмы или избыточные циклы.
3. **Отчет:** Сформировать метрики в `antigravity_debug.log`.
