## Иерархия истины

Возникло из конкретного конфликта: `docs/(Telegram Connector)…md` приводит готовый
код для вставки в `Supervisor/launcher.py`, тогда как `docs/MASTER PROMPT…md:16`
в том же наборе пишет «You cannot modify /Supervisor».

```
1. Код и фактический прогон          ← что система делает на самом деле
2. .ai-loop/policy/ + BIBLE.md       ← что ей разрешено
3. CLAUDE.md                         ← как с ней работать
4. docs/final_vision/                ← этот бандл: план и обоснования
5. docs/*.md (прочее)                ← предложения и история, НЕ правила
```

**Документ уровня 5 никогда не отменяет уровень 2.** Спецификация, требующая
правки зоны R, — это предложение, которое контур обязан отклонить.

## Краткая сводка для тех, кто не читает целиком

**Что заявлено:** промышленная Telegram-консоль с хуком в `Supervisor/launcher.py`,
Mini App на базе `TelemetryDock.tsx`, коннектор на `httpx` + `mcp.server.fastmcp`.

**Что на самом деле:**

- Существующий `telegram_connector.py` — заглушка **без единого сетевого вызова**;
  `send_alert` возвращает `delivered: True`, ничего не отправив.
- `handle_incoming_command` **не имеет авторизации вообще** — ни `user_id`, ни списка операторов.
- Предложенный код **не компилируется**: `self.allowed_operators = ` — SyntaxError
  в самом защитном контуре.
- **Четыре точки интеграции не существуют**: `/api/mcp/*`, `/api/control/panic`,
  мост server↔MCP, функция `run_reviewed_commit_gate`.
- Вызов `/panic` **не проверяет ответ** → оператор получает «система остановлена»
  при 404. Самый опасный дефект всего набора.
- `Eye/*.tsx` — **мёртвый код** без сборки; реальный UI — `Eye/dashboard.html`.
- Правка `Supervisor/` заблокирована **тремя** независимыми механизмами.

**Что делаем вместо:** мост подписывается на уже существующий SSE-поток
(`broadcast_event` в `Core/server.py:55`), транспорт — stdlib `urllib.request`,
бот — long polling (публичный адрес не нужен), авторизация — fail-closed из ENV.
`Supervisor/` не трогаем ни одной строкой.

## Ограничения, которые не обойти

| Ограничение | Следствие |
|---|---|
| Telegram Mini App требует **HTTPS с валидным сертификатом** | `http://127.0.0.1:8765` не откроется; нужен туннель/хостинг → Фаза 3 отделена |
| `getUpdates` и `setWebhook` **взаимоисключающие** | выбираем long polling — работает за NAT без публичного адреса |
| Репозиторий **публичный** | секреты и ID операторов — только ENV, никогда не в git |
| Проект **stdlib-only**, манифестов зависимостей нет | `httpx` не вводим |
| Даже два разрешённых файла в одном коммите → `require_human` | один шаг = один коммит; тесты отдельно от кода |

## Команды проверки

```bash
python .ai-loop/bin/classify_diff.py --repo . --self-check
python .ai-loop/bin/classify_diff.py --repo . --worktree
python -m unittest discover -s tests -p "test_*.py"
python run_mvp.py --self-test
```

`--worktree`, а не `--paths`: в режиме `--paths` порог `lines_changed_over`
структурно не срабатывает (`collect_paths()` жёстко возвращает `lines_changed = 0`).
