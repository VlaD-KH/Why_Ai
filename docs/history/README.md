# docs/history/ — уровень 4 иерархии истины

Иерархия зафиксирована в `.ai-loop/context.md` и в `docs/final_vision/README.md`:

```
1. Код и фактический прогон          ← что система делает на самом деле
2. .ai-loop/policy/ + BIBLE.md       ← что ей разрешено
3. CLAUDE.md                         ← как с ней работать
4. docs/final_vision/                ← текущий бандл: план и обоснования
5. docs/history/ (этот каталог)      ← предложения и черновики, НЕ правила
```

Всё здесь — **история**, а не источник правил. Ничто из этого каталога не отменяет
`docs/final_vision/` и тем более не отменяет `.ai-loop/policy/`. Часть документов прямо
противоречит проверенному коду (см. таблицу ниже) — они оставлены как есть, потому что
это ценный документ намерения на момент написания, а не потому что их утверждения верны.

## Известные недостоверные утверждения (не исправлены — исторические документы)

- `research/Сравнительный аудит…Ouroboros и Claudexor.md` — содержит вымышленные номера
  версий и метрики, опровергнутые `self-evo/Что такое Ouroboros фактически.md`
  (фактическое, проверенное по GitHub API исследование того же вопроса).
- `dvpn/Оценка. Проверка готовности и инструкция для польз.md` — заявляет
  «production-ready»; прямо противоречит `final_vision/01-audit.md` и
  `06-self-evo-audit.md`.
- `telegram/MASTER PROMPT_ Telegram Mini App & FastMCP Bot Integration.md` и
  `telegram/Why_Ai v1.1.0-Gold.md` — приводят код для `Supervisor/launcher.py`,
  что запрещено зоной R; отвергнуто, разбор — `final_vision/01-audit.md`.

Два документа с Telegram ID оператора (`docs/(Telegram Connector)…md`,
`docs/https___github…txt`) сюда **не перенесены** — перенос требует правки `.gitignore`
(зона P), решение оставлено человеку. Они остаются в корне `docs/`, видимы только в
основном чекауте (gitignored).
