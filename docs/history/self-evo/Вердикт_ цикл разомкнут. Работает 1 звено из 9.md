## **Минимальный набор недостающего, по убыванию критичности**

1. **Актор синтеза** — вызов модели, который получает `refactor_plan` \+ контекст файлов и пишет реальные правки **внутрь** `sandbox["absolute_path"]`. Сейчас в репозитории нет ни клиента, ни ключа, ни точки вызова. Без этого остальные восемь пунктов бессмысленны.  
2. **Реальное применение и слияние** — в `verify_and_merge` заменить литерал на `git -C <sandbox> add/commit` \+ `git merge --no-ff sandbox/<id>` с обработкой конфликтов и ненулевого кода возврата. Дифф должен браться из `git diff` песочницы, а не из f-строки, иначе сверка SHA-256 охраняет пустоту.  
3. **Верификация в песочнице** — прогон `tests/` внутри worktree до кворума. Сейчас между созданием и удалением песочницы не выполняется ничего; «shrink-only» проверяется только `record_baseline()` (:171) уже **после** мнимого слияния.  
4. **Починка контракта звена 2** — либо `generate_refactor_plan()` должен возвращать `patterns` и `total_failures`, либо `IdempotencyGate` читать `steps` и `total_failures_recorded`. Однострочная правка, но пока цикл достижим только через `--force`, то есть в обход собственного предохранителя.  
5. **Откат** — снимок `git rev-parse HEAD` до слияния и `git reset --hard` при провале тестов. Сейчас неудачный цикл нечем отменить.  
6. **Подключение ledger** — вызовы `ledger.append` на границах фаз и снятие условия `hashFiles` в CI (`ai-loop-enforcement.yml:101`), чтобы отсутствие журнала было ошибкой, а не молчаливым пропуском.  
7. **Автопополнение `failures.jsonl`** — вызов `record_failure` из обработчиков реальных сбоев (`panic_stop`, отказ кворума, красные тесты). Это то, что замыкает цикл обратно на источник задачи; сейчас все 3 записи внесены вручную.  
8. **Писатель `identity.md`** — код, дописывающий веху после успешного цикла. Сейчас манифест описывает возможности, которых у системы нет.
