## ── ПЕРЕНОСИМОСТЬ & WINDOWS-СОВМЕСТИМОСТЬ ──

### [ ] Task 4. Очистка от абсолютных путей (Path Decoupling)
*   **Проблема:** В файлах `implementation_plan.md` и `walkthrough.md` зашиты жесткие абсолютные пути вида `file:///c:/Users/Huawei/...`.
*   **Решение:**
    *   [ ] Провести рефакторинг всех манифестов, конфигураций и путей импорта в Python-скриптах.
    *   [ ] Заменить их на репозиторно-относительные пути (используя `pathlib.Path(__file__).resolve().parents[...]`).

### [ ] Task 5. Защита цифровых отпечатков (CRLF Invariant)
*   **Проблема:** Разница в окончаниях строк (CRLF на Windows, LF на Linux) ломает хэш-отпечатки диффов (`Fingerprints`) при создании Git Worktree.
*   **Решение:**
    *   [ ] В процесс инициализации изолированных песочниц добавить принудительное выполнение команды:
        ```bash
        git config --local core.autocrlf false
        git config --local core.eol lf
        ```
    *   [ ] Написать тест, подтверждающий идентичность хэша файла, созданного на Windows и Linux.
